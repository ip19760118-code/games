Онлайн через Firebase (как в Шахматах/Дураке). Выход из комнаты сразу гасит твой статус «онлайн» у соперника.

📖 Правила

• Поле 10×10, буквы А–К, цифры 1–10.
• Флот 1×4,2×3,3×2,4×1; не касаются углами.
• Расстановка: 1‑е нажатие = мигающее превью, 2‑е = подтвердить; либо 🎲 Авто.
• Онлайн: создай комнату → 📨 Пригласить → друг открывает ссылку (пилюля станет зелёной с 2) → оба расставляют флот и жмут «⚔️ В бой!».
• Над полем противника — легенда: маленькие корабли и сколько осталось; потопленный тип прозрачный.
• Попадания по твоему полю помечаются синим крестом (cross_blue.png), по противнику — красным.
• ⛶ Во всю ширину — раскрыть поля на всю ширину экрана (мобильный).
